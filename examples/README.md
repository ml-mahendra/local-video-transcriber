# Example commands

```bash
local-transcribe
local-transcribe "/path/with spaces/my demo.mkv"
local-transcribe --folder "/path/to/recordings" --model small
local-transcribe --folder "/path/to/recordings" --recursive --language auto
local-transcribe "/path/to/recording.mp4" --output-root "/path/to/output"
```

No example media files are bundled to keep the project lightweight.
